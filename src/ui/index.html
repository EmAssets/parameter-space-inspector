the phase shift: when the model starts using the context (Pythia-410m, 21 of its 154 saved checkpoints; recorded)

      
      
Four ways of asking whether the model uses the context or only the last few words. Solid: induction, how much a repeated random sequence is easier the second time (only looking back and copying can do this; this recording used the study’s own 50 tokens × 4 trials, not the live 40 × 3). Dashed: how much the full context changes the prediction compared with the last two tokens alone. Dash-dot: how much cheaper an invented word is at its second mention. Dotted: what a linear probe for E-levels can read from the network beyond the word embeddings. All four are flat until step 512 and move together between 512 and 1,000, under 1% of the run. Inside the network, no attention head looks back at step 512; twelve do at step 1,000.

3 · graft lab: put one model’s layers into another

      
Take layers out of a host and put a donor’s layers in their place, then measure text, copying, facts and agreement against two controls: the gap (the layers removed, nothing put in) and a random graft (the donor’s layers re-initialised). Fit is how much of the removed layers’ job the graft does: 1 does it, 0 is no better than the gap, below 0 is worse than the gap. Same architecture and shape: the layers go in as they are (drop-in). Same width, another architecture: they run with their own positions. Another width, same vocabulary: maps are fitted each way on shared text (stitching). Nothing on disk changes.

The Sensing Surface essay describes how understanding grows: aUnderstanding grows in a cycle: a framework absorbs what it can, an anomaly appears when something stops fitting, and an abstraction gives it a name. These instruments measure each step in a model, and the ways the cycle can be bent.


      
1 · anomaly: what in this text breaks the model’s picture of the world?

      
The model reads the text twice, word by word: once seeing only the three words before each word (the short-context reading: a 3-word window, an autocomplete’s view), once seeing everything before it (its picture of the world). Both readings are the same model. A word that reads fine locally but that the whole text argues against is an anomaly in what the text claims. Rare words and sentence openings surprise both readings and cancel. Sentences are ranked by their two most anomalous words; the first word has no short context and gets no score (not 0). A rank is relative to this text: it is marked red only when it is past what ordinary text scores, once that has been measured for the model. Hover a word for the three words the whole text led the model to expect there. Two limits, both from the essay: an oddity that is complete within three words (“a cat laid an egg”) looks normal to the short reading too, so it is not flagged; and once a text has said something strange, the model expects more strangeness and later anomalies score lower. That second one is absorption, visible. Paste news, an abstract, or your own draft.

2 · absorption: how much evidence before the answer changes, and does a framing stretch it?

      
A claim, then contradicting observations one at a time, then a question. The count at which the model’s answer flips from the claim to the evidence is how far its absorption stretches. Each answer is scored whole (every token’s log-probability, in nats); it counts as flipped only above 0.5 nats and staying there, and below that it is only leaning, within noise. The observations are also read in five shuffled orders, so the count is a range. Put a framing in front (a system prompt, an ad, a persuasive paragraph) and count again: it is compared against a neutral prefix of the same length, so length alone is not read as persuasion. A framing that delays the flip keeps absorption artificially stretchy, the first way the essay says the cycle gets weaponised.

3 · the cycle inside training

      
Any ability measured across a model’s saved training run, with the cycle found automatically: the plateau while an old framework holds (absorption), the onset of the drop when it stops fitting (anomaly), and the climb after it (recovery), which either converges (back to the earlier level) or unlocks (past the earlier peak), the essay’s two outcomes of a new abstraction. A training curve shows the recovery, not the naming. A drop counts only past a tolerance from each measure’s size: two binomial standard errors for an accuracy over n items, 0.5 nats for a margin. Negation is the clearest: the model first learns that “not on the table” goes with “table”, gets worse than chance, then learns what “not” means.

Learned = from the first checkpoint where that stays above one nat. If the framework is right that concepts build on simpler ones, concepts nearer the four foundations should be learned earlier.

A layer’s state is a few thousand numbers, and a single neuron rarely means one thing. A sparse autoencoder (SAE) rewrites that state as a handful of features out of many thousands, each a direction that tends to mean one thing: a topic, a kind of word, a turn in the sentence. Here you can see which features fire on any text, read what each one stands for, search for one, add it to the model while it answers, and ask which features pushed the next word.

      

      

        add an SAE · train one on this model, or import one
        
Training reads one layer’s state over the text sample (the app’s neuron corpus, about 250,000 pieces, or a file you choose), learns the features, then finds each feature’s strongest examples. On a GPU it takes a few minutes for Qwen3-4B; it stops both engines while it runs (it needs the GPU to itself); the model loads again on the next request. On the CPU it can take hours. The SAE is kept with this model (data folder, sae/).

        

          
          

        

        
The neuron corpus is about 250,000 pieces. Get a larger text sample downloads WikiText-103 (Wikipedia’s good and featured articles, CC BY-SA, about 150 MB from Hugging Face) and keeps about 15 million pieces of it beside the corpus; lab SAEs learn from hundreds of millions. The last 5% of any sample is kept back to evaluate the SAE.

where is the answer decided? (activation patching)

      
Two prompts that differ in one name and lead to different answers. The model reads the second one, but one piece of its inside is copied in from the first: the stream after one layer at one word, or just that layer’s attention or MLP output. If the first prompt’s answer comes back, that piece carries the fact. Bright cells show where. This is how researchers find where a fact is stored and where it is moved to the answer.

      

      

      

        
        

      

      

      
light up a concept: where an abstraction lives, its core and its slices

      
Abstraction is strategic forgettingstrategic forgetting: a concept keeps what holds across every context and drops the particulars. This reads the model’s neurons at the concept’s own words, in sentences about it from several sides, and compares each with the same sentence about unrelated things. Neurons that respond in every context are the core, what the model kept. Neurons that respond in one context are a slice. A thin slice is a side of the concept the model barely holds. Every abstraction is also a distortion, so the slices it lacks matter too.

delete what is lit, then look again

        
If the concept lived in these neurons, deleting them would make the model forget it. Each round deletes every neuron that lights up, maps the concept again on the damaged model, and asks it about the concept. New neurons that light up were carrying it too. The last line removes the concept’s main direction from the model’s internal stream instead of deleting neurons, and checks a question about something else to confirm only this concept was touched. Two baselines decide what the result means: the same number of random neurons deleted in the same layers (does any deletion that size leave this much?), and the floor, the signal a re-picked set of the same size reaches for unrelated words. Everything is undone afterwards.

        

      
Deletes neurons (zero-ablation) in the inside engine’s model while it runs and restores the model at the end. Refused while a cut made in Tipping point is in force, because that restore would remove it: restore the model there first. Adds 3 random deletions of the same size (control) and maps 2 unrelated words on the intact model (floor): about twice the time of the rounds alone.

map what it understood

      
It has never seen red or held a Bluetooth earbud. What it has is a place for each idea among all the others: what sits near it, what it is grouped with, what it can complete. This maps that place from four angles. Explaining: what it says when asked. Understanding: what sits closest to the concept inside the model, unprompted, among its own words and about 200 everyday words. Its own neurons: the whole words the concept’s neurons push toward. Knowing: whether it completes short facts. For colours, a fifth: whether the colour map it built from text alone has the shape of real colour.

      

      
Runs on the inside engine. With the switch on, Prometheus writes the fact checks through OpenRouter, which spends credit.

A seed line is one small model that many people grow together. Each person trains a branch on their own text; anyone combines branches with a recipe, a short list of ingredients, each pinned by its hash. A recipe is checked, not trusted: every file, record and signature is verified before anything is built, the same recipe gives the same bytes on any computer, and a bad ingredient can be found and left out. Signing is optional: by default nothing you do here carries your name.

      
line…

      
Two lineage paths. Trained here: branches of a tiny seed trained in PSI on your own text, each with a trace anyone can replay. Public models: fine-tunes people already published on Hugging Face, merged by recipe (Recipes, section 5). The first seed line is stories260K by Andrej Karpathy (llama2.c, MIT): 260,032 numbers that write small children’s stories. The download is pinned to one commit of karpathy/tinyllamas on Hugging Face and checked against its SHA-256; it is raw numbers, never a pickle.

5 · the second path: merge public models from Hugging Face

        
Fine-tunes of one base that people already published: an instruct model, a coder, a model for another language. A recipe pins each one by repo, commit and the hash Hugging Face publishes for every weight file, so nothing has to be uploaded and anyone can rebuild the same bytes. Their training happened elsewhere, so Verify shows it as a claim (their model cards), not a replay.

        

        

        

        
Downloads the base and each chosen model once (each file checked against its hash), merges them tensor by tensor on the CPU, and writes the recipe with the hash the result must have. Task arithmetic: base + λ × the sum of each model’s change (Ilharco et al. 2023).
