# Contributing

Thanks for your interest in the Parameter Space Inspector.

- **Questions, results and ideas:** start a thread in [Discussions](https://github.com/EmAssets/parameter-space-inspector/discussions).
- **Bugs:** open an issue with the bug report form: what happened, the steps, your version and setup.
- **Security problems:** report them privately (see [SECURITY.md](SECURITY.md)), never in a public issue.
- **Code changes:** please open an issue or discussion first, so we can agree on the approach before you spend time on
  it. Keep changes focused, match the style of the surrounding code, and check that `node --check` passes on changed
  JavaScript and that the app still starts (`PSI_SELFTEST=1 npm start` drives the basic views and exits).

By contributing you agree that your contribution is licensed under the [Apache License 2.0](LICENSE), like the rest of
the code. The Emergence Machine's content listed in [NOTICE](NOTICE) is not open for contributions or reuse.

Please follow the [code of conduct](CODE_OF_CONDUCT.md).
